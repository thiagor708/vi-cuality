Fundamentos
de calidad

Construcción de pruebas (TDD)

Práctica que garantiza la calidad mediante el diseño de pruebas automatizadas antes de la escritura del código base.

Criterio de hecho (DoD)

Acuerdo explícito que establece las condiciones de calidad requeridas para considerar que un incremento de software está completamente terminado.

Calidad en entornos ágiles (Scrum)

La calidad no depende únicamente de seguir un proceso rígido, sino del talento, el conocimiento tácito del equipo y la entrega continua de valor operativo.

Las métricas son medidas cuantitativas que permiten evaluar el estado, rendimiento y calidad tanto del producto de software como del proceso de desarrollo.

Métricas de producto

Evalúan características internas o externas del software.

Métricas de proceso

Evalúan la eficiencia del flujo de trabajo.

ISO/IEC 9126 e ISO/IEC 25000 (SQuaRE)

Estándar internacional histórico que define un modelo de evaluación de la calidad del software dividido en 6 características principales:
Funcionalidad: capacidad del software para satisfacer las necesidades declaradas.
Fiabilidad: capacidad para mantener un nivel especificado de rendimiento.
Usabilidad: facilidad de aprendizaje, comprensión y uso del software por parte del usuario.
Eficiencia: rendimiento y optimización de recursos.
Mantenibilidad: facilidad para modificar, corregir o actualizar el software.
Portabilidad: capacidad del software para ser transferido de un entorno a otro.
