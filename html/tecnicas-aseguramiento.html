Cuadro comparativo de niveles de prueba en la gestión de calidad de software.

Nivel de prueba
Enfoque principal
Elementos probados / entorno
Unitarias
  • - Centrado en componentes aislados.
  • - Prueba unidades mínimas de código.
  • - Funciones.
  • - Métodos.
  • - Clases.
  • - Módulos.
Integración
  • - Centrado en interacción y comunicación.
  • - Prueba la conexión entre componentes.
  • - Dos o más módulos previamente probados.
  • - Flujos de datos entre ellos.
Sistema
  • - Centrado en el sistema completo como un todo.
  • - Evalúa comportamiento funcional y no funcional.
  • - Sistema integrado al 100%.
  • - Entorno similar al de producción.

Información sobre cajas

Caja blanca: Es un sistema que permite conocer y analizar su funcionamiento interno, observando los procesos y las operaciones que realiza para obtener un resultado.

Caja negra: Es un sistema que permite observar los datos que ingresan y los resultados que se obtienen, sin conocer cómo funciona internamente.
